# SQL Database Design & Data Migration Project

## Overview
This project demonstrates practical SQL skills through the design and development of a relational database. It focuses on database structure, data integrity, and preparing data for migration between legacy and updated database schemas.

The project simulates a business environment where customer and order information must be organized, validated, and maintained across database versions.

## Project Objectives
- Design relational database tables.
- Establish primary key and foreign key relationships.
- Implement database constraints to maintain data integrity.
- Work with legacy and updated database structures.
- Practice SQL data manipulation and database validation.
- Develop foundational skills applicable to data migration and database testing.

## Database Structure

The project includes tables representing:

- **Customers:** Stores customer information, including names, contact details, and timestamps.
- **Orders:** Stores customer transactions, including order dates, amounts, and statuses.
- **Legacy and Updated Schemas:** Demonstrates how database structures can evolve over time.

## SQL Skills Demonstrated

- CREATE TABLE
- INSERT INTO
- Primary Keys
- Foreign Keys
- NOT NULL Constraints
- Data Types
- Relational Database Design
- Data Integrity
- Schema Management

## Project Organization

The project is organized into separate SQL files and folders to keep database creation, constraints, and data management organized and maintainable.

## Purpose

This project is part of my continued development as a QA Engineer, with an emphasis on SQL, database testing, and data migration.

It demonstrates hands-on practice with relational database concepts and provides a foundation for more advanced SQL validation and testing scenarios.
